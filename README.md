# Samraiz Aziz | Flutter Application Developer

A responsive React, TypeScript, Vite, and Three.js developer portfolio.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Portfolio content

Project, experience, service, and technology data lives in `src/portfolio.ts`. Add your LinkedIn and Instagram profile URLs there when available. Project entries intentionally distinguish supplied projects from concepts and leave unavailable demos, screenshots, and implementation details unclaimed.

The contact form creates an email draft in the visitor's mail app; it does not submit data to a server.
